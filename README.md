# Inventory Management Frontend

This repository contain frontend of the Inventory Management.

### Prerequisites

- Node.js (v20.14.0)
- npm (10.7.0)

### Getting Started

1. Clone the repository:
```commqndline
git clone https://github.com/iamj33l/Inventory-Management-Frontned.git
cd Inventory-Management-Frontend
```

2. Install dependencies:
```commandline
npm install
```

3. Start the server:

- Make sure the backend server is running on `http://localhost:8000`. Find the backend repository [here](https://github.com/iamj33l/Inventory-Management-Backend).

```commandline
npm start
```
